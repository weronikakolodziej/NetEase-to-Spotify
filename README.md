# 🎵 NetEase → Spotify Chrome Extension

A lightweight Google Chrome extension designed to seamlessly migrate your liked songs and playlists from NetEase Cloud Music (`music.163.com`) directly to Spotify.

## Setup
Navigate to `background.js` and fill in the values for `SPOTIFY_CLIENT_ID` and `SPOTIFY_CLIENT_SECRET`


## 📦 Chrome Installation

1. Open Google Chrome and navigate to `chrome://extensions`
2. Enable Developer mode - switch in the top right corner.
3. Click the `Load unpacked` button in the top left corner.
4. Select the root folder `netease-chrome-extension`
5. Pin it to the toolbar 

##  Usage

1. **Navigate to [music.163.com](https://music.163.com)** and log in to NetEase
2. Click on the extension icon (puzzle → NetEase→Spotify)
3. Click click
